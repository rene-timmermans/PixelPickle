PixelPickle: quick guide

PixelPickle is a photo editor for Linux with the familiar layout of classic Windows photo editors: menus, tools and shortcuts are where you expect them.

The workspace

  • Menu bar and standard toolbar at the top: files, editing, adjustments, effects, layers and selections.
  • Tool options bar below it: the settings of the current tool, such as size, hardness and opacity. Use the Presets button to save and load your own settings.
  • Tools toolbar on the left. A button with a small arrow holds more tools: click the arrow to choose. Without an open image the toolbar is greyed out; with the first image the last used tool is active again.
  • Palettes on the right: Materials, Layers and History. Show or hide them via View > Palettes.
  • Right-click the image, a tab or a layer for a context menu.

Opening, creating and saving images

  • File > New creates an empty image; File > Open opens existing files.
  • Saving with layers: .pspimage or .ora (OpenRaster). Common formats such as PNG, JPEG, TIFF, WebP and GIF save a merged image; your layers stay in PixelPickle.
  • Several images open at once: switch with Ctrl+Tab.

Tips:

  • The left mouse button paints with the foreground color, the right button with the background color.
  • Hold the space bar and drag to pan the image.
  • While selecting, the image scrolls along when you reach the edge of the window.
  • Crop: drag a rectangle, adjust it with the squares on its corners and sides, and double-click inside it (or press Enter) to crop.
  • Text: click to create text, or click existing text to edit it again.

Materials: color, gradient and pattern

  • The top box is the foreground (and the outline of shapes), the bottom box the background (and the fill). Click a box to open Material Properties.
  • There you choose a color, a gradient (linear, rectangular, sunburst or radial, with angle and repeats) or a pattern (with angle and scale; an open image or your own file works too).
  • The small buttons under a box switch quickly between color, gradient and pattern; ⊘ makes it transparent (no outline or no fill). ⇅ swaps foreground and background.
  • Gradients and patterns work with the flood fill, brushes and shapes.

Layers

  • Create layers, groups, masks and adjustment layers via the Layers menu or the buttons in the Layers palette.
  • Set opacity and blend mode per layer. An adjustment layer (for example Curves) changes everything below it without touching the pixels; a mask controls where.
  • Double-click a layer for its properties.

Adjustments and effects

  • Each dialog shows a before and after preview; you can zoom and pan the preview.
  • Save settings as a preset to recall them quickly later.
  • Effects > Effect Browser shows the effects side by side with a preview.

Undo

Ctrl+Z undoes, Ctrl+Alt+Z redoes. The History palette lists every step; click an earlier step to go back.

Preferences

  • File > Preferences > General Program Preferences: the language (Dutch or English).
  • File > Preferences > Autosave Settings: keeps changed images in a recovery folder every few minutes. If PixelPickle closes unexpectedly, it offers to restore them on the next start. Your own files are never overwritten.
